# Design Context — NetVera İnşaat Firması Web Sitesi Pro

## Target audience
- Alanya / Antalya bölgesinde villa, konut, ticari yapı, renovasyon veya anahtar teslim proje planlayan bireysel yatırımcılar ve işletmeler.
- Arsa sahibi, mülk sahibi, küçük/orta ölçekli yatırımcı ve güvenilir bir uygulama firması arayan müşteriler.
- Teknik detaydan çok güven, süreç şeffaflığı, referans/proje kanıtı ve iletişim kalitesine bakarak karar veren kullanıcılar.

## Main user jobs
1. Firmanın gerçek ve güvenilir olup olmadığını hızlıca anlamak.
2. Hangi hizmetin kendi projesine uygun olduğunu görmek.
3. Tamamlanan / devam eden projelerden kalite seviyesini değerlendirmek.
4. Bütçe, süreç, teslim ve saha yönetimi konusunda güven sinyali almak.
5. Telefon veya WhatsApp üzerinden kolayca ön görüşme başlatmak.

## Brand personality
- Premium ama gösterişsiz.
- Kurumsal ama soğuk değil.
- Teknik, düzenli, güven veren.
- Yerel saha deneyimi güçlü.
- Mimarlık/editoryal kalite taşıyan gerçek insan tasarımı.
- AI template estetiğinden özellikle kaçınır.

## Visual direction
- Poppins.
- Maksimum 1200px container.
- 8px spacing rhythm.
- Desktop sakin ve editorial; mobile gerçek yeniden akış.
- Ana renk: koyu lacivert.
- Accent: kontrollü sıcak turuncu/bakır.
- Arka planlar: kırık beyaz, açık taş, gerektiğinde koyu lacivert.
- Premium hissi fotoğraf, tipografi, oran ve boşluktan gelir; efekt yoğunluğundan değil.
- Gerçek proje fotoğrafı UI dekorundan daha önemlidir.
- Hizmetler: taranabilir liste/dizin.
- Projeler: fotoğraf ağırlıklı editorial portfolio.
- Güven unsurları: kompakt ve gerçek.
- CTA: az, net, kompakt.

## Hard anti-patterns
- Her sectionı card grid yapmak.
- Pill/chip/rozet kalabalığı.
- Her karta shadow + border + radius aynı anda vermek.
- Emoji veya Unicode tik/ok ile UI tasarlamak.
- Gereksiz glow/gradient/glassmorphism.
- Fazla küçük body typography.
- Dev boşlukları "premium" sanmak.
- Aynı küçük uppercase kicker + dev başlık + 3 kart şablonunu sürekli tekrar etmek.
- Yapay yorum kartı görünümü.
- Fotoğrafın önüne geçen UI.

## Technical constraints
- PHP/MySQL ürün sürümü ve statik GitHub Pages demo sürümü paralel tutulmalı.
- Sıfır harici JS tercih edilir; mevcut vanilla JS korunur.
- Semantik HTML, görünür focus, alt text/title alanları.
- prefers-reduced-motion desteklenmeli.
- Mobile touch target minimum 44px.
- Admin alanlarından gelen dinamik içerik tasarımı bozmamalı.
